# 아성보이스 (Asung Voice) Website

AI 음성 인식 기반 워치독 비명감지기 — 공식 홈페이지 리디자인

## 미리보기

```bash
python3 -m http.server 8080
# http://localhost:8080
```

## GitHub Pages

이 저장소는 GitHub Pages로 자동 배포됩니다.
- URL: https://gourry7.github.io/asungvoice/

## 내부 일정 보드 (대표·이사)

공개 메뉴에는 없습니다. 주소만 세 분에게 공유하세요.

- 경로: `/ops/`
- 로그인: 이승현(대표), 공찬희(이사), 이사 — 각자 비밀번호
- 표 셀을 눌러 수정하고 **공유 저장**을 누르면 GitHub를 통해 세 명 화면에 반영됩니다.
- 게시판 관리자에서 이미 GitHub 토큰을 넣었다면 같은 브라우저에서 그대로 됩니다.
- 초기 비밀번호는 내부 전달 후, 보드 → 설정에서 반드시 바꾸세요.
